# VeriFi

A social media app on finance, where everyone needs to stand their word

## Project Structure

This project is a full-stack application with:
- **Backend**: Django REST Framework API (Python)
- **Frontend**: React + TypeScript + Vite

## Quick Start

### Prerequisites

- **Python 3.12+** (for backend)
- **Node.js** (for frontend)
- **pnpm** (frontend package manager)

### Backend Setup

See [backend/README.md](backend/README.md) for detailed backend initialization instructions.

### Frontend Setup

See [frontend/README.md](frontend/README.md) for detailed frontend initialization instructions.

## Running the Full Application

1. Start the backend server (runs on port 8000 by default)
2. Start the frontend development server (runs on port 5173 by default)
3. Open http://localhost:5173 in your browser
